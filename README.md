# NTC Andar - strona firmowa

Motyw WordPress `ntc-andar` i wtyczka wdrożeniowa `ntc-deploy` dla
NTC ANDAR Sp. z o.o. Staging: https://ntc-strona.salescons.pl

## Struktura

- `ntc-andar/` - motyw (bloki serwerowe, szablony, style)
- `ntc-deploy/` - wtyczka wdrożeniowa (wysyłka plików, wsadowe operacje na treści)
- `tools/` - skrypty wdrożeniowe

## Uwaga

Repozytorium jest odtwarzane po utracie kopii roboczej. Źródłem prawdy
jest w tej chwili kod zainstalowany na serwerze staging.
